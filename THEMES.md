Theme: "Sentinel" — Campus Command Center

Concept: Instead of a soft, friendly SaaS dashboard, design it like a security control room interface — the same visual language used in surveillance systems, access-control panels, and command centers. This immediately communicates authority, vigilance, and real-time monitoring, which fits guards/admins scanning IDs and logging violations far better than a pastel productivity app would.

Color Palette
Base: Deep charcoal/near-black (
#0D1117–
#151A21) as the primary background — reduces eye strain for guards using it at night/during long shifts, and reads as "serious system," not a toy
Primary accent: Amber/safety-orange (
#F5A623 or 
#FF8C00) — the universal color of alerts, warning tape, and security signage. Use it for active states, scan confirmations, primary buttons
Status colors, used sparingly and consistently:
Green (
#2ECC71) — cleared/compliant/resolved
Red (
#E74C3C) — violation/flag/non-compliant
Blue-gray (
#5B7A99) — neutral/informational (visitor logs, attendance)
Text: Off-white (
#E6E6E6) on dark, never pure white (too harsh against black)
Typography
A monospaced or semi-monospaced font (like JetBrains Mono or IBM Plex Mono) for IDs, timestamps, QR codes, and log entries — reinforces the "systems/terminal" feel and makes scan data feel authoritative and precise
A clean geometric sans (Inter or IBM Plex Sans) for headings, labels, and body copy so it doesn't feel like a hacker movie — balance authority with usability
Signature UI Motifs
Scan-line / radar sweep animation on the QR scanner screen — a subtle rotating scan line while the camera searches, like a badge reader, rather than a static camera box
"Badge card" reveal — when a student/visitor QR is scanned, their profile animates in like a security ID badge sliding into place (photo, name, ID number, status chip) rather than a plain form popping up
Status chips everywhere — small pill-shaped tags (Cleared / Flagged / Pending / Resolved) with the color-coding above, used consistently across attendance, violations, and compliance records
Corner-bracket framing (⌐ ¬ style corner marks, like camera viewfinders) around the live QR scan area and around key stat cards on the dashboard — a small detail that reinforces "monitoring system" without being kitschy
Grid/dot-pattern background texture at very low opacity on the dashboard — evokes blueprints/schematics, keeps large dark areas from feeling empty
Role-differentiated dashboards
Guard interface: stripped down, big-tap-target mobile-first layout, dominant scan button front and center, minimal chrome — built for speed with one hand while standing at a gate
Admin interface: denser data-table layout, charts for violation trends/visitor volume, report generation panel — built for a desk, not a phone
Iconography
Custom line-icon set (not default Material/FontAwesome) styled like security/access-control signage: shield, badge, gate/turnstile, camera aperture for scanning, clipboard-check for compliance — thin 1.5px stroke weight, consistent corner radius
